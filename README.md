## 🚀 Быстрый старт

Сайт — это статическая HTML-страница, поэтому для запуска достаточно открыть `index.html` в любом браузере или развернуть на любом статическом хостинге (GitHub Pages, Netlify, Vercel и т.д.).

### Локальный запуск

Просто откройте файл:

```bash
# Windows (двойной клик по файлу)
start index.html
```

Или через локальный сервер (рекомендуется для полной функциональности):

```bash
# Python
python -m http.server 8080
```

### Параметры запуска

Сайт автоматически активируется после даты открытия (`2025-07-07-22T10:00:00+03:00`).

Для принудительного показа сайта добавьте параметр `?dev=true`:

```
index.html?dev=true
```

## 🛠️ Технологии

- [**Tailwind CSS (CDN)**](https://cdn.tailwindcss.com) — утилитарный CSS-фреймворк
- **Vanilla JavaScript** — вся логика на чистом JavaScript
- **Google Analytics (gtag)** — аналитика событий
- **RuTube Embed** — встраивание видео
- **Twitch Embed API** — клипы и хайлайты Twitch
- **Canvas API** — анимированный фон с эмодзи-частицами

### 🎨 Адаптивный дизайн
- Полная поддержка мобильных устройств
- Бургер-меню для навигации на маленьких экранах
